# OIBSIP_web-development_03

Oasis Infobyte level1-Task 3 – Temperature Converter Website
 
 ⭐ Objective
The objective of this task is to develop a Temperature Converter Website using HTML, CSS, and JavaScript that allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin easily and accurately.

  🛠 Tools Used
- HTML5  
- CSS3  
- JavaScript  
- Visual Studio Code  
- GitHub  

  📝 Steps Performed
1. Designed the webpage structure using HTML.  
2. Styled the website using CSS for a clean and responsive interface.  
3. Added an input field for users to enter temperature values.  
4. Included dropdown menus/radio buttons to select temperature units.  
5. Implemented temperature conversion logic using JavaScript.  
6. Added validation to ensure users enter valid numeric values.  
7. Displayed the converted temperature result dynamically.  
8. Tested the website and fixed errors for accurate conversion.  
9. Uploaded the completed project files to GitHub repository.

   🎯 Outcome
A fully functional Temperature Converter Website was successfully created.  
The application accurately converts temperature values between Celsius, Fahrenheit, and Kelvin with an interactive and user-friendly interface.

  📂 Project Files Included
- `index.html` — Main webpage structure  
- `style.css` — Website styling and layout  
- `script.js` — Temperature conversion functionality  
- `README.md` — Documentation for the task.
